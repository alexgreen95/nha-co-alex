# Admin-only Gạch bông experiment

Open the palette menu and choose **Gạch bông cổ điển (Thử nghiệm)** after signing in as an admin. Choose any existing theme to leave. Selection is memory-only for the current document/account: reload returns to the existing saved theme; logout/account switch removes the experiment immediately. No trial value is written to localStorage, sessionStorage, profiles, or a shared preference.

The controller requires the current auth-account object, a hydrated profile owned by that account, and `profiles.role === admin`. Display name, email, URL parameters, and stored theme names do not grant access. A fresh read of that account's `profiles(id,role)` is required before activation. Failed reads/timeouts deny. Active visible documents recheck every 30 seconds and on focus/visibility return; locally hydrated role changes revoke immediately. Remote role changes are detected by the next successful check (at most the 30-second interval plus the bounded read while visible), not by a new realtime subscription. A read aborts after 8 seconds; failure disables the feature. Background tabs recheck when they become visible.

The CSS and chosen tile image load only after a permitted selection. CSS is scoped to `body.gach-bong-admin`; the presentation helper is private to the gated controller. Static assets contain no private data. Existing auth, RLS, schema, push, progress, route code, and the seven existing theme definitions are unchanged.

Refine v2 is preserved: the original tile JPEG (SHA-256 `0af1c84465bce112089dae2bd74e1433b85e0746889100ef5917093bfea80734`), no tile wash, the original `/alex-banner.jpg` with no filter/fade overlay in this theme, the cubic SVG nameplate, and background-only paragraph highlight. Existing title/author/chapter/nav/comment nodes retain their IDs and handlers. Temporary wrappers/ResizeObserver are removed on exit. Switching keeps the same visible paragraph at the same viewport position; Chromium scroll rounding observed was 0.234375 px. Prose geometry/font/line breaks remain identical.

Validation uses real application DOM/scripts with mocked Supabase responses. It covers verified admin, normal account, guest, pending/mismatched/failed profile checks, stored-name/query injection, logout, stale response after account switch, remote/local role loss, 30-second polling, seven old themes, three reader widths (1440/390/320), long titles, comments and chapter navigation. No live admin credentials were used. Existing auth bootstrap regressions also run. The test-only static server was repaired to serve actual local assets and stub analytics rather than returning index.html as JavaScript; the same failure was reproduced on the original main before repair.

Trial aesthetics still under review: tile size/contrast, retained asset watermark, plaque proportions for long mobile titles, corner details, and how the unchanged original banner colors sit with the warm tile palette. No public release is enabled by this commit.
